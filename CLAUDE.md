# CLAUDE.md — guidance for Claude Code sessions on this repo

## Commit authorship — required

Always author commits and pushes as **Martin Dinov <martin@maaind.com>**, never as Claude.

If the local git author isn't set to that already, fix it before the first commit of a
session:

```bash
git config user.name  "Martin Dinov"
git config user.email "martin@maaind.com"
```

This applies to **every** commit, on any branch (`main`, `claude/*`, feature branches).
Don't use `--author` overrides or co-author trailers that re-attribute to Claude either.

## Branch / push

Develop on whatever branch the session was spawned on. Push only when explicitly asked. The
canonical branch is `main`; the previous feature branch `claude/vigilant-planck-ZQRtN` is
already merged in. Don't force-push to `main` without explicit confirmation.

## Other house rules

- Don't add Claude/Anthropic identifiers (model IDs, "Generated by Claude", etc.) to commit
  messages, code comments, or any artifact pushed to the repo.
- Don't `--amend` published commits or rewrite history on shared branches without a clear
  user request.
- The full test suites must pass before pushing: `python3 -m pytest tests/` (149 tests)
  and `cd web && npm test` (9 JS tests, including Python ↔ JS cross-compat).

v6 · a programming language you can hear

Write Python and it plays as chords; the decoder reconstructs the program from those notes. Or compose by ear below and watch the program emerge — optionally constrained so only valid programs can be built. And as a side feature, hide a message or image inside the audio, imperceptibly.

Determinism: a program + your compositional choices fully determine the music; the music fully determines the output. There is no randomness in the system — “variation” is a choice you make, not chance. Each opcode owns a family of distinct chords (the redundancy), so the same instruction can sound many ways, yet every chord maps back to exactly one opcode.
